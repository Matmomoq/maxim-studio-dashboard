## Запуск тестов без доступов к данным

Python 3.10+; основной набор проверен на 3.10.21.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest test_dashboard test_amocrm_loader test_security -q
```

94 теста используют тестовые записи и временные настройки. Рабочие БД и `.env` для них не нужны. Строгого lock-файла зависимостей пока нет; диапазоны заданы в `requirements.txt`.

## Локальный запуск приложения

```bash
cp .env.example .env
# Заполните .env доступами к отдельному тестовому окружению.
python run_dashboard.py
```

Адрес: http://127.0.0.1:8080. Пароль и независимый случайный `DASHBOARD_SECRET_KEY` обязательны. `DASHBOARD_COOKIE_SECURE=false` допустим только для локального HTTP. `run_dashboard.py` включает debug и слушает только localhost; для публичного сайта используйте WSGI без debug.

Без подготовленных БД можно выполнить тесты и открыть страницу входа; настоящая аналитика требует таблиц и данных amoCRM/YCLIENTS. Полноценного демонстрационного режима и наполнения фиктивными данными в этом комплекте нет.

## Что входит

- `dashboard/` — Python-расчёты, HTML, CSS, JS и бизнес-настройки классификации;
- `amocrm_client.py`, `amocrm_loader.py` — OAuth-клиент и загрузчик amoCRM;
- `db_security.py` — проверяемое TLS-подключение к MySQL;
- SQL-схемы и четыре добавляющие миграции управленческих таблиц;
- `docs/yclients-schema/` — структура источника YCLIENTS, без клиентских данных;
- тесты, примеры настроек, WSGI-точка входа и шаблоны GitHub Issues/PR.

Нет рабочих секретов, клиентских выгрузок, дампов БД, логов, архивов и SSH-ключей. Отдельный загрузчик YCLIENTS не включён: приложение читает уже подготовленную БД; схемы переданы для понимания контракта данных. Идентификаторы CRM-этапов, сотрудников и бизнес-правила сохранены там, где они нужны для точного воспроизведения логики. Репозиторий должен оставаться приватным.

Пуш в этот репозиторий сам по себе **не обновляет рабочий сайт**. Автодеплой не подключён.
